# Domain glossary

DOCUMENTED definitions from the cited contract/code; “avoid” aliases obscure the stated grain or certainty.

- **Event** — Gamma grouping of related markets; avoid “trade event” for this entity. [gsd-final:.planning/phases/02-design/02-DATA-SPEC.md §2.2]
- **Market** — Prediction question with outcomes, market ID and condition ID; avoid treating these IDs as an asset ID. [gsd-final:.planning/phases/02-design/02-DATA-SPEC.md §2.1–2.2]
- **Outcome** — Labelled possible result within a market, mapped by index to an asset; avoid “market” when ranking an outcome. [gsd-final:fabric/gamma_logic/selector.py build_mapping]
- **Asset** — Outcome token identified by a long decimal string used for subscription; avoid numeric coercion or “market ID.” [gsd-final:fabric/gamma_logic/selector.py build_watchlist]
- **Frame** — One received WebSocket message: object, array or text; avoid equating frame count with fact count. [gsd-final:collector/envelope.py]
- **Entry** — One logical child after object/array and `price_changes` expansion; avoid “frame” for each child. [gsd-final:collector/envelope.py]
- **Capture** — Collector observation assigned a stable identity at receipt; avoid “unique source event.” [gsd-final:collector/envelope.py]
- **Capture identity** — Frame `session/frame_seq`, entry `session/frame_seq/entry_idx`, interval `session/gap/segment_id`; retry keeps identity. [gsd-final:collector/envelope.py]
- **Source event identity** — Source-guaranteed unique event key; UNVERIFIED for this feed; avoid calling capture ID a source ID. [gsd-final:.planning/phases/02-design/02-DATA-SPEC.md §2.4]
- **Source duplicate** — Repeated content received from source, whose economic identity may be unknown; avoid silently deduplicating trades by payload. [gsd-final:.planning/REQUIREMENTS.md REL-02]
- **Re-delivery** — Repeated delivery of the same capture downstream; dedupe by capture ID; avoid “duplicate trade.” [gsd-final:fabric/kpi_logic/reference.py dedupe_by_capture_id]
- **Connected segment** — Recorded interval of collection coverage; not proof every source observation was delivered; avoid “complete market history.” [gsd-final:fabric/kpi_logic/reference.py build_coverage]
- **Gap** — Explicit unavailable interval/loss record, possibly manifest-only after failed sink send; avoid “zero activity.” [gsd-final:.planning/phases/03-build-ingest/03-CONTEXT.md D3-08]
- **Quote freshness** — Age of last source quote change, separate from receive/ingest/render age; avoid “ingestion latency” for book age. [gsd-final:.planning/phases/02-design/02-DATA-SPEC.md §2.4]
- **Connection health** — Coverage/heartbeat state, independent of quiet quote age; avoid “stale price” as a synonym for disconnected. [gsd-final:fabric/kpi_logic/reference.py spread_connection_state]
- **Midpoint** — `(best_bid+best_ask)/2` for valid two-sided quote; avoid “last trade” or “calibrated probability.” [gsd-final:fabric/kpi_logic/reference.py dedupe_by_capture_id]
- **Percentage point (pp)** — `100 × price difference` on 0..1 scale; avoid relative “percent change.” [gsd-final:fabric/kpi_logic/reference.py _mover_one]
- **Trade observation** — Received `last_trade_price` observation; avoid “all executions” or summing outcomes into unproven market volume. [gsd-final:.planning/phases/01-inception/01-DATA-SPEC.md §1.4.3]
- **Metadata version** — Published complete discovery/mapping artifact pinned by a session; avoid “latest source state.” [gsd-final:fabric/gamma_logic/publish.py publish_snapshot]
- **Watchlist hash** — SHA-256 of compact JSON of sorted unique asset ID strings; not a hash of all labels/rules/statuses; avoid “metadata version.” [gsd-final:fabric/gamma_logic/selector.py watchlist_hash]
- **Session** — One collector run from open to close, pinning exactly one metadata version; the unit of batch processing and backfill; may contain several connected segments; avoid “segment” or “run” for it. [restart grilling 2026-10-24 D11]
- **Quarantine** — Capture excluded from cleaned data for violating a quality rule, retained with its rule ID for inspection; a row-integrity rule may keep the row in Silver and only exclude it from Gold facts ([ADR 0012](docs/adr/0012-row-level-gate.md)); avoid “deleted” or “dropped”. [restart grilling 2026-10-24; ADR 0012]
- **Commit timestamp** — Time of the Delta commit in which a Bronze row became visible (CDF `_commit_timestamp`); orders what Silver has not consumed yet; avoid `file_modification_time`, `EventProcessedUtcTime` (stamped before Eventstream batches rows into files) or `received_at` (collector clock, old for replays) as the order. [ADR 0008]
- **ETL watermark** — Per-layer value up to which a successful run has read its input: `silver` = commit timestamp of the last Bronze commit consumed, `gold` = start of the last successful Gold run (compared with Silver `process_timestamp`); advanced only after success, reset to rebuild; avoid calling it a streaming checkpoint offset. [ADR 0008]
- **Gate** — Row-level quality gate: a row that breaks a row rule goes to quarantine and stays out of the tables built from it, nothing blocks a session or a run; Soda results are warn-only, in `ops.dq_result`; avoid “blocking check”, “blocked session” or “DQ job”. [ADR 0012; ADR 0006 was the blocking gate]
- **Scenario** — Named, self-contained Bronze-shaped dataset (with manifests and mapping, optionally ordered batches), loaded into `scn_<name>` catalog tables for the hybrid Silver notebook / Gold dbt play and compared with the oracle; also the isolated target for `fntk` snippets. The only scenario run area is `scn_<name>`; see [Test loop](docs/environment.md#test-loop). Avoid “fixture” for the uploaded dataset.
- **Notebook session** — Live Spark session used for `fntk` snippet iteration; variables persist between runs. Distinct from a collector Session. Copy working code into the repo notebook, run pytest, deploy one item, then a layer test per change and one full play before merge; [setup, rules and cleanup](reference/fabric-cli.md#notebook-toolkit-fntk).
- **Item folder** — A workspace item in Fabric Git format, `fabric/Polymarket-DEV/<name>.<Type>/`, imported unchanged by `loop deploy`; the source of truth for that item; avoid “generated notebook” or “wheel”. [ADR 0009]
- **Answer key** — The rows every run-area table should hold after a given batch of a scenario, computed by the oracle at check time (`fabric/testkit/scenario.py answer_key`), Soda outcomes and watermark rows included; never stored; avoid “expected output” for one table only or “golden file”. [architecture review 2026-10-26, ticket 08]
- **Plan** — The ordered steps of a scenario (push a batch, run a stage, probe a table, check, snap, same) that `loop play` runs through `fabric/testkit/play.py run_plan` against a workspace; a step that does not do what it states stops the plan; avoid “test script” or “pipeline” for it. [architecture review 2026-10-26, ticket 10]

- **Layer test** — One pipeline layer run on oracle-seeded inputs, comparing only that layer's output tables (Soda: only its rules). Gold uses `dbt_scenario_gold`, derived from the production dbt project; tests never redeploy `dbtJob_1`. Uses one cumulative snapshot; `play` covers incremental behaviour. [Test loop](docs/environment.md#test-loop)
- **Change map** — Literal path-glob to layer mapping in `fabric/testkit/changes.py`; `loop test --changed` combines merge-base, staged, unstaged and untracked paths into ordered `(gate-rules, layer)` tests. Unclassified item folders and testkit modules fail; explicit ignores select no Fabric test.
- **Seed** — Input tables written from the answer key and the scenario's Bronze, manifest and mapping through a batch, into `scn_<name>` for a layer test. A Scenario's `silver_edits` apply only to the `soda-silver` seed; its layer answer computes Soda counts from those rows. The play and other layer seeds do not apply them. [fabric/testkit/layer.py]
